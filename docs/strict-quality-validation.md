# 엄격한 내용 완성도 테스트

2026-10-03. 모두 가상 지원 건이며 실제 심사위원의 점수·합격 확률이 아니다.

## 평가의 독립성

평가자는 작성자의 이전 PASS/리뷰/설명을 보지 않고 문항과 본문을 먼저 읽은 뒤 카드와
대조했다. 사실과 형식, 심사에 필요한 정보의 깊이를 별도로 판단했다. 체크리스트/인터뷰
같은 행동 이름이나 분량 비율이 아니라 실제 문제·행동 내용·선택 기준·과정·관찰 결과·
언어·중복·차별 정보가 얼마나 평가 가능한지 엄격하게 검토했다.

| 사례 | 사실/형식 | 별도 내용 판정 | 실제 관찰 |
|---|---|---|---|
| 한국어 협업 갈등 403/600자 | PASS | ADEQUATE | 구체적 인터뷰/표 공유/제안, 개인과 팀 구분. 합의 과정과 판단 기준에 개선 여지 |
| 영어 최소 원자료 32/500단어 | PASS | THIN | 문제·체크리스트 내용·선택 근거가 없어 실질 능력을 평가하기 어려움 |
| 새 풍부한 원자료 156/500단어 | PASS | ADEQUATE | 실제 항목/선택/피드백/직접 사용/원본 대조. 확인 결과는 세 건으로 제한, 반복/마무리 개선 가능 |

세 번째 사례는 **새 합성 원자료**로 만든 별도 건이다. 기존 실제 지원자에게 추가 사실을
얻었다는 의미가 아니다. 작성자 자체 STRONG 평가를 그대로 따르지 않고 독립 ADEQUATE
평가를 최종 기록에 적용했다. 영어/한국어 모두 기본 완성과 최고 품질을 구분한다.

## 발견과 실제 보완

기존 사실·요건 PASS가 내용의 깊이까지 보장하지 못했다. 이를 보완해 다음을 적용했다.

- content-quality.md: 문항별 STRONG/ADEQUATE/THIN/NOT_READY 기준과 근거 기반 판단.
- Planner: 행동 이름만 있는지를 확인하고 필요한 실제 디테일의 질문 목적을 기록.
- Writer: 승인된 과정·선택·관찰을 사용하며 수식어·반복으로 분량을 늘리지 않음.
- Reviewer: 문항/본문 우선 심사 후 카드 대조, 각 문항의 평가·차단 갭·개선 여지를 기록.
- validator/export: 내용 평가 누락, THIN/NOT_READY, 열린 차단 갭을 실제로 차단.
- 최종 확인: 내용 등급과 개선 여지를 사용자에게 함께 공개.

기존 32단어 영어 건의 factual/format PASS를 유지한 채 THIN 평가를 입력하면
`Q-01: content too thin or not ready; clarify evidence before export`로 거절하며 새로운
output을 만들지 않는다. 새 156단어 건은 ADEQUATE로 READY_FOR_USER_REVIEW까지 검증했다.
실제 사용자 최종 승인과 지원 사이트 제출은 없다.

## 풍부함과 질문

‘길게 써라’가 아니라 ‘어떤 문제를 보고 무엇을 만들었는지/왜 골랐는지/어떻게 확인했는지’
실제 사실을 요청한다. 한국어 예시에는 ‘공유한 표의 구성, 반대 의견의 반응, 합의까지
본인이 한 행동’을 확인하면 더 깊어질 수 있다. 모르면 다른 소재/현재 한계를 사용하며
같은 질문을 반복하거나 효율·매출·리더십을 창작하지 않는다.

등급은 내부 판단이다. 기계는 기록의 계약·최신성·차단 조건을 검사하며 의미나 등급을
자동 추론하지 않는다. 별도 평가자끼리 의견이 다르면 근거 차이를 공개하고 더 높은
등급만 골라 최종 결과를 포장하지 않는다.
