# 자연스러움과 내용 품질 점검

파일 이름은 이전 버전 호환을 위해 유지한다. AI 탐지기·AI 작성 여부 판정표가 아니다.
문장부호, 균등한 리듬, STAR 구조 자체는 결함이 아니다. 탐지기 점수 최적화, 일부러
오류 넣기, AI 사용 금지 공고에서 숨기기를 하지 않는다.

## 언어별 선택 점검

한국어: 추상적 수식·상투적 다짐·직역투가 실제 행동 설명을 가리는가? 첫째/둘째나
대칭구문이 내용의 관계를 잘 설명하면 사용할 수 있다. 합쇼체/평서체는 선택된 설정을 따른다.
영어: 능동태·실제 역할 동사·일관된 시제·자연스러운 어휘인가? 세미콜론·dash·I는
문맥에 맞으면 허용된다. 한국어 ‘귀사의 무궁한 발전’, ‘열정으로 이바지’를 직역하지 않는다.

## 내용 점검 12항목

| 항목 | 확인할 것 | 문제가 있을 때 |
|---|---|---|
| 주장-근거 거리 | 주장 강도가 실제 행동·자료와 맞는가 | 범위 축소 또는 실제 근거 확인 |
| 인과 압축 | 관찰과 인과를 혼동했는가 | 기여·확인 범위 구분 |
| 행위 주체 | 개인/팀·제안/결정/실행이 맞는가 | 역할 필드 대조 |
| 선택의 흔적 | 실제 선택과 이유가 드러나는가 | 없는 의사결정 창작 금지 |
| 경험 고유성 | 행동·장면·산출물이 구체적인가 | 카드의 디테일 활용 |
| 문항 간 중복 | 같은 사건/국면/교훈을 반복하는가 | 다른 측면 또는 소재 배치 |
| 과잉 완결성 | 실패를 허위 성공으로 마무리하는가 | 실제 한계 유지 |
| 키워드 에코 | 공고 인재상만 반복하는가 | 실제 행동 설명 |
| 템플릿 골격 | 문항을 제쳐두고 STAR를 강제하는가 | 요구 하위요소에 맞춤 |
| 핵심어 자기복제 | 같은 역량명만 여러 번 나오는가 | 근거가 설명하게 함 |
| 회사 적합성 | 묻는 동기에 본인의 실제 이유가 있는가 | FIT 확인, 독점 사실 강요 금지 |
| 인과의 공백 | 해결 과정이 빠지고 결과만 있는가 | 승인된 과정 또는 주장 축소 |

surface_check.py와 dedup_check.py는 위 항목의 일부 후보만 찾는다. 모든 후보는
문맥을 읽고 판단한다. 표현 선호를 탈락 기준으로 승격하지 않는다.
